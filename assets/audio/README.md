# Audio overrides (optional)

`AudioBus` synthesizes soft BGM/SFX at runtime. Drop files here to replace them:

| File | Role |
|------|------|
| `bgm_soft.ogg` | Looping background |
| `ui_tap.wav` | UI click |
| `screw_turn.wav` | Unscrewing |
| `part_snap_out.wav` | Part removed |
| `part_snap_in.wav` | Part snapped back |
| `success_chime.wav` | Repair complete |
| `cassette_loop.wav` | Cassette function |

Prefer warm, quiet, CC0/licensed-for-your-release assets.
